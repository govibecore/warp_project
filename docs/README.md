# WARP Documentation

Welcome to the comprehensive documentation for the WARP project. 

WARP is an offline-first STEAM competency assessment built using React, Vite, and Tailwind CSS. The documentation is split across several key areas to make it easy to understand the system's architecture, business logic, and UI design.

## Documentation Index

- [Architecture & Persistence](./architecture.md): Overview of the technology stack, folder structure, and how offline data is managed.
- [Domain Logic & Assessment](./domain_logic.md): Deep dive into the scoring algorithms, session management, dynamic scenarios, and competency reference norms.
- [UI Components & State](./ui_components.md): Explanation of the React component tree, UI routing, and how state is passed down to components like the Assessment and Dashboard views.
- [Testing Strategy](./testing.md): Information on how to test the application, covering both unit testing with Vitest and end-to-end testing with Playwright.
