## Glade hero — visual smoke test caught a real bug

Headless vitest (jsdom + no WebGL) **cannot compile GLSL** — every shader error would silently pass tsc, vite build, and all 54 tests, then paint a black hero. So after the logic tests passed, I drove a real Chromium via Playwright (SwiftShader for WebGL):
- Downloaded `chromium-headless-shell` via `npx playwright install chromium` (~115 MB).
- Wrote `glade-smoke.cjs` (throwaway, deleted): navigated to localhost:5199, decoded screenshots inside the page via `getImageData` (no PNG decoder needed in Node), measured mean luminance + dark fraction + distinct colors in three zones, captured console errors (three.js logs `THREE.WebGLProgram: Shader Error ...` to console.error).
- **First run, the glade rendered and animated with no shader errors — but mean RGB was [47,58,46], luminance 0.24, darkFraction 0.47. The site defaults to dark theme** (`--background: oklch(0.16)`) and my full-width scrim `from-background via-background/85 to-background/20` was washing the whole hero in near-black — directly violating spec §1 "bright, not dark". By temporarily `display:none`-ing the scrim divs and remeasuring, the raw painting came in at mean [137,180,112], luminance **0.65, darkFraction 0**. Diagnosis: scrim was the cause, glade itself was perfect.

**Fix:** confined the scrim to the copy column (left ~70% of width), left the right 30% fully bright. Narrowed copy from `max-w-2xl` to `max-w-xl` so it sits entirely inside the dense scrim zone. Used an arbitrary-value Tailwind gradient `bg-[linear-gradient(to_right,var(--background)_0%,var(--background)_34%,color-mix(in_oklab,var(--background)_86%,transparent)_52%,transparent_70%)]` with explicit stops. Final measurements: textZone 0.14, textRightZone 0.16 (no light leak at the copy's right edge), gladeZone 0.622 (full brightness).

**Final shipped state:** 54/54 tests, `pnpm verify` clean, hero confirmed visually bright + legible in real Chromium. The brutal lesson: for any GLSL work, **a real browser smoke is mandatory** — headless tests are structurally silent on shader correctness.

## Tailwind/Playwright recipe worth keeping
- Playwright: `npx playwright install chromium` downloads Chrome Headless Shell (~115 MB) to `~/AppData/Local/ms-playwright/`.
